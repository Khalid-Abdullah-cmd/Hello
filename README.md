# 🛠️ Git & GitHub Learning Sandbox

Welcome! This repository was created as a safe, simple environment to practice using Git and GitHub. 

There is no pressure to write perfect code here. This is a space to break things, fix them, and understand how version control works.

## 📂 What's inside?
Right now, this repo just contains a simple `hello.html` file. We are using this file to practice making changes, saving them, and collaborating.

## 📝 Quick Command Cheat Sheet
Here is a quick reminder of the everyday Git commands you'll be using:

* `git status` — Shows you what files have been changed but not yet saved.
* `git add .` — Stages all your changed files to be committed.
* `git commit -m "your message"` — Saves your staged changes locally with a descriptive note.
* `git push` — Uploads your local commits up to this GitHub repository.
* `git pull` — Downloads the latest changes from GitHub to your computer.
* `git log` — Shows the history of all the commits we've made.
* `git checkout <branch-name>` — Switches your working directory to another branch. *(Tip: Add `-b` like `git checkout -b new-branch` to create a new branch and switch to it instantly!)*
* `git merge <branch-name>` — Takes the code from the branch you specify and combines it into the branch you are currently on.
* `git reset <commit-hash>` — Acts like a time machine. It undoes recent commits and moves your project back to a previous state. *(Warning: Use this carefully, as it rewrites history!)*
  

Happy coding! 🚀
